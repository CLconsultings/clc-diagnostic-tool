# Security Policy

## Supported version

Only the current release on `main` is supported.

## Reporting

Do not disclose suspected vulnerabilities in a public issue. Report them to
CLConsulting through an authorized private business channel with the affected
version, reproduction steps, impact, and any known containment.

## Release handling

Security corrections follow `RELEASE_GOVERNANCE.md`. A material vulnerability
blocks release. If a released defect could affect confidentiality, integrity,
availability, or decision outcomes, external use stops until containment or a
verified corrective release is available.

Never commit credentials, client data, assessment responses, or private
evidence to this repository.
